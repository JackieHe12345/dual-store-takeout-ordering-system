# 顾客端

Vue 3 + Pinia，A/B 店共用此界面，通过各自路径请求所属门店 API。

收货地址可从门店配置的常送地址列表选择，也可主动点击浏览器定位，取得收货点后补充小区/街道名称与楼栋门牌。常送地址搜索在本地筛选，不需要地图 Key；定位不请求外部地图服务，不会根据手填文字猜测坐标。浏览器定位通常要求 HTTPS 或 localhost，拒绝权限或精度超过 200 米时会提示选择常送地址或重新定位。

保留地址列表、新增/编辑、默认地址和标签。地址和已选地址仅保存在当前浏览器设备，按门店入口区分；浏览器存储被禁用时会显示提示。旧 GCJ_02 地址继续保留，新增定位点使用 WGS_84，常送地点支持 WGS_84、GCJ_02、BD_09。

外送结算请求服务端计算直线距离与档位配送费，仅配送范围内且费用已确认时计入预计合计。门店位置未确认、配送费未设置或查询失败时显示不可用状态，不依赖地图服务 Key。

在生产配置启用交易能力时，已实现菜单、搜索、购物车、会员登录、报价、提交未支付订单和订单进度查询；在线支付尚未接入，订单提交后由门店确认。关闭交易能力时，页面会回退到仅提供菜单、购物车和联系门店入口的基础界面。
